# 搜索意图

## 意图簇

- 品牌 + product / distributor / supplier
- 工业自动化设备供应商
- PLC、HMI、drive、switchgear、instrumentation 等品类 + supplier
- industrial automation system design installation commissioning
- measurement and analytics instruments supplier
- industrial automation partner / system integrator / OEM support

## 页面策略

产品页需支持按品类、品牌和应用进入；服务页回答设计、安装、调试的范围；询价页支持料号、BOM、规格书和项目需求；关于页建立公司可信度，但不以未经证明的授权和客户 Logo 作为唯一证据。

关键词国家、语言和优先品类需在确认销售重点后冻结。
